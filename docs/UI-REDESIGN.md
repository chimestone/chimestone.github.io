# 博客界面与内容方案 v4

日期：2026-10-28。站点：https://chimestone.github.io/ 。

## 页面结构

深色、极简、以阅读为主。沿用 Hugo、Hextra、Markdown 和 GitHub Pages 自动部署。

| 区域 | 内容 |
| --- | --- |
| 左栏 | GitHub 头像、名字、个签、GitHub / RSS、搜索、主要导航、按主题折叠的文章树、主题切换 |
| 中栏 | 首页为主标题、一句话介绍、最近五篇文章；其他页面为文章列表或正文 |
| 右栏 | 首页留白；文章显示章级目录、阅读进度和回到顶部 |

不使用重复指路卡片、按钮组、英文装饰标签和重复阅读链接。左侧个人信息固定，文章树单独滚动。宽屏保留弹性三栏和受限的正文行宽；1100px 及以下隐藏右栏，760px 及以下使用单栏正文与导航抽屉。手机文章顶栏固定提供章节目录入口，搜索保留在全站导航中。主题菜单从左下方向上展开。

## 视觉与交互

近黑底色、灰白文字、细分隔线和留白。主标题保留 0.035em 字间距，保留小幅浮现、链接微交互和减少动态效果支持。

背景猫固定在右下角：桌面宽 50vw，手机宽 64vw，低对比、左侧渐隐，不拦截点击。素材记录见 [猫素材说明](assets/cat-reference.md) 和仓库第三方声明。

导航树展开当前分类。章节高亮结合 CSS 实际滚动留白计算阈值，保证锚点跳转后高亮正确。手机目录选择章节后关闭并返回正文。

## 内容与分类

| 分类 | 文章 |
| --- | --- |
| 计算机系统 | 逻辑与计算机系统设计；从 C 代码到可执行文件 |
| 数据库 | 数据库系统基础 |
| 数学基础 | 离散数学（二） |
| 工具与实践 | Git 操作笔记 |

同一课程目录合并为一篇：数据库十章、数字系统九章、离散数学的主题与证明分别整理为三篇长文。重复简记中的独有内容经修正后补入。每篇一个主分类，标签标识具体知识点，不把原笔记库的所有文件夹都做成栏目。

原有 C、Git 文章通过显式 url 保持原路径，测试文章旧地址仍跳转至 Git 笔记。章节用二级标题，章内细分用三级及以下标题，目录只列章级内容。

## 筛查与整理边界

入选目录经过凭据、联系方式、本机路径和本机引用规则扫描，并人工检查正文。检查范围不是整个笔记库；原始笔记不修改，也不由 CI 自动同步。

教材题目截图、课件截页、依赖原题的答案合集不公开；空白高级计数章节在文章中标明仅有提纲。消除重复元数据、失效课件导航，修正已发现的逻辑公式、计数条件、密码模型、范式、缓存和流水线表述。每篇保留相关参考来源，作为持续修订的个人学习整理。

## 公式与长文

数学公式使用 Hugo transform.ToMath 在构建时输出原生 MathML，不额外加载公式脚本和远程字体。严格检查公式语法，现代浏览器直接显示。公式外层与宽表格限制在正文范围内，长公式可独立横向滚动，避免撑宽手机页面。

## 验证与维护

- 正式构建；检查站内链接、锚点、重复 ID、各合并稿的章节覆盖与公式输出。
- 桌面核对分类、目录与全文搜索；手机核对固定目录入口、跳转、自动关闭和无页面横向溢出。
- 作者信息在 hugo.yaml，首页介绍在 content/_index.md，文章在 content/blog/ 四个分类目录中。
- 发布通过对应提交的 GitHub Actions，最终状态以部署运行记录为准。

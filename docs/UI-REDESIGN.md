# 博客界面与内容方案 v3

日期：2026-10-28。站点：https://chimestone.github.io/ 。

## 页面结构

深色、极简、以阅读为主。沿用 Hugo、Hextra、Markdown 和 GitHub Pages 自动部署。

| 区域 | 保留内容 |
| --- | --- |
| 左栏 | GitHub 头像、名字、个签、GitHub / RSS、搜索、首页 / 博客 / 关于导航、文章树、主题切换 |
| 中栏 | 首页为主标题、一句话介绍、最近五篇文章；其他页面为文章列表或正文 |
| 右栏 | 首页留白；有章节的文章显示目录、阅读进度和回到顶部 |

删除重复指路卡片、首页按钮组、右侧最近更新和话题、英文装饰标签、重复阅读按钮。文章入口直接使用标题链接。左侧个人信息固定，文章树单独滚动。

宽屏保留弹性三栏和受限的正文行宽；1100px 及以下隐藏右栏，760px 及以下改用导航抽屉和单栏正文。手机可通过“本文目录”打开章节导航。主题菜单从左下方向上展开。

## 视觉与交互

保留近黑底色、灰白文字、细分隔线和留白，主标题保留 0.035em 字间距。保留小幅浮现、链接微交互和减少动态效果支持。

背景猫使用用户指定的透明素材，独立固定在右下角：桌面宽 50vw，手机宽 64vw，低对比、左侧渐隐，不拦截点击。眼睛跟随、触屏静态策略及素材记录见 [猫素材说明](assets/cat-reference.md) 和仓库第三方声明。

搜索、导航树、移动端模态导航、原生章节锚点和现有 CI/CD 沿用原实现。

# 博客界面改版方案 v1

日期：2026-10-27。目标站点：https://chimestone.github.io/ 。

## 1. 已确认的方向

深色、简约、适合长期阅读的个人博客。首页帮助访客认识作者和寻找内容，文章页保持文档式阅读体验。沿用 Hugo、Hextra、Markdown 与 GitHub Pages 自动部署。

## 2. 三栏布局

| 区域 | 内容 | 滚动行为 |
| --- | --- | --- |
| 左栏 | 名字、头像/首字母、简介、社交链接；首页/博客/关于入口；全站文章树 | 左栏固定在视口；上部个人信息固定，下部文章树独立滚动 |
| 中栏 | 首页介绍、阅读指路、精选/最近文章；分类索引；文章正文 | 使用浏览器原生页面滚动，不劫持滚轮 |
| 右栏 | 首页：最近更新与 RSS；文章页：本文目录、阅读进度、回到顶部；下部背景猫 | 保持在视口内；长目录独立滚动，背景猫不遮挡内容 |

宽屏三栏；中等屏幕隐藏右栏，文章目录通过按钮打开；手机用模态抽屉显示左栏，正文保持单栏。窄屏保证可关闭、焦点可返回且键盘能操作。

## 3. 首页信息结构

1. 简短问候与作者介绍：沿用现有真实内容。
2. 清楚的主标题与阅读入口。
3. 阅读指路：文章、关于两个真实入口，栏目不足时不虚构分类。
4. 最新文章：从博客内容自动生成，按时间倒序，展示真实日期和标签。

## 4. 视觉规范

- 近黑底色、柔和灰白正文、低对比细线，少量冷灰光感。
- 标题与正文形成清楚层级，正文行宽适合长文。
- 玻璃质感仅用于浮层和少量表面，不让正文背景复杂化。
- 卡片低幅度抬升、链接箭头轻移、内容短时交错浮现。
- 默认深色，保留主题切换。没有虚构统计、自动播放声音或持续抢注意力的动画。

## 5. 交互规范

- 搜索：沿用 Hextra 的全文搜索、快捷键和键盘结果选择。
- 全站目录：当前页面高亮，当前分组默认展开，保存手动展开状态及目录滚动位置。
- 正文目录：自动由 Markdown 标题生成，点击跳转，随阅读位置高亮；不生成空目录模块。
- 阅读进度：根据正文实际位置更新，提供回到顶部按钮。
- 动效：主要使用 cubic-bezier(0.16, 1, 0.3, 1)，小幅、短时；减少动态效果偏好下关闭位移与追踪。
- 无 JavaScript 时正文、普通链接、目录树仍然可以使用。

## 6. 背景猫：用户已选择

参考：黑底、灰白线稿、从底部探头、眼睛跟随鼠标。用户已明确接受 **Tabler MIT 开源 cat SVG** 作为现成素材，适配探头构图和视线跟随。

- 来源：https://github.com/tabler/tabler-icons/blob/main/icons/outline/cat.svg
- 许可：https://github.com/tabler/tabler-icons/blob/main/LICENSE
- 保留原始轮廓；调整显示尺寸、颜色、裁切和瞳孔绑定。
- 瞳孔追踪参考现成公开眼睛跟随实现，保留来源及许可说明。
- 背景猫放在右栏底部，轮廓低亮度，眼睛适度更亮，不截获正文点击。
- 触屏与减少动态效果模式使用静态姿态；页面隐藏、猫不可见或指针停止后不持续运算。
- 不提取 Wallpaper Engine 场景；不声称 Tabler 猫与参考图完全相同。

## 7. 内容与维护

作者名、简介、个人链接集中配置在 hugo.yaml。无指定头像时显示作者名首字母。原有文章、URL、全文搜索与 CI/CD 保持可用。博客索引改为自动列出文章，减少手工维护链接。

## 8. 验收

- Hugo 正式构建成功，首页、博客索引、文章、关于、标签页正常。
- 桌面三栏，左侧个人区不随目录滚动，正文不溢出；手机单栏与可关闭抽屉。
- 搜索、目录折叠、锚点、阅读进度、主题切换、猫眼追踪正常。
- 支持键盘焦点、Escape 关闭、减少动态效果；没有运行时脚本报错。
- 第三方素材和许可留在仓库。
- 本地检查通过后提交、推送，通过现有 GitHub Actions 发布并核对实际站点。

## 9. 实施记录

已按本文档完成实现：

- 新增站点三栏布局覆盖与可配置个人信息，不更换 Hugo/Hextra 技术栈。
- 首页介绍、阅读指路、最近文章；博客索引自动列出文章；标签页、关于页保留。
- 导航树独立滚动与状态记忆；手机模态导航及目录；保留全文搜索与主题切换。
- 右栏按页面变化，正文目录高亮、阅读进度与回到顶部。
- 使用已获用户确认的 Tabler cat 素材，附上游原始 SVG、固定来源提交和 MIT 许可；已有鼠标视线算法适配到 SVG 坐标，离开页面时停止计算。
- 动效采用轻量 CSS 与按需动画帧，不添加前端框架。

本地验证（2026-10-27）：

- Hugo Extended 0.157.0 正式构建通过；自定义 JavaScript 语法检查通过。
- 生成站点 9 个 HTML 文件的 203 个本地链接/资源检查通过，没有重复 HTML ID 或失效锚点。
- 桌面 Chrome 实际检查首页、文章页、三栏布局与背景猫，猫眼跟随有可见位置变化。
- 390×844 手机尺寸实际检查：单栏排版、导航抽屉、从抽屉进入搜索、关闭返回、目录弹层与章节跳转均正常。
- 搜索实际返回文章结果；深色主题菜单正常；修复旧主题手机菜单脚本冲突后，新页面错误日志为空。

实际边界：当前内容只有一篇文章，首页与右栏按真实内容展示；未编造分类和统计。Tabler 猫为用户批准的几何线稿改编，与参考图的手绘毛边轮廓不同。减少动态效果与触屏使用静态追踪策略。改版发布结果以仓库的 Build and deploy blog 运行记录为准。

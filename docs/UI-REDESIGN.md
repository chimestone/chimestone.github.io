# 博客界面改版方案 v2

日期：2026-10-27。目标站点：https://chimestone.github.io/ 。

## 1. 已确认的方向

深色、简约、适合长期阅读的个人博客。首页帮助访客认识作者和寻找内容，文章页保持文档式阅读体验。沿用 Hugo、Hextra、Markdown 与 GitHub Pages 自动部署。

## 2. 三栏布局

| 区域 | 内容 | 滚动行为 |
| --- | --- | --- |
| 左栏 | 名字、GitHub 头像、简介、社交链接；首页/博客/关于入口；全站文章树 | 左栏固定在视口；上部个人信息固定，下部文章树独立滚动 |
| 中栏 | 首页介绍、阅读指路、精选/最近文章；分类索引；文章正文 | 使用浏览器原生页面滚动，不劫持滚轮 |
| 右栏 | 首页：最近更新与 RSS；文章页：本文目录、阅读进度、回到顶部 | 保持在视口内；长目录独立滚动 |

宽屏三栏采用 18:64:18 的弹性列，保留侧栏最小可读宽度，整体不设置固定最大宽度。间距、页边距、头像、标题及正文使用 vw/clamp 随视口变化，长文保留 78ch 的阅读行宽上限，不整体缩放网页。1100px 及以下隐藏右栏，文章目录通过按钮打开；760px 及以下用模态抽屉显示左栏，正文保持单栏。窄屏保证可关闭、焦点可返回且键盘能操作。

背景猫独立于右栏，固定在视口右下角，桌面宽度 50vw、手机宽度 64vw；受视口高度限制，保持图像比例。背景图层不接收点击，左侧渐隐，避免影响正文阅读。

## 3. 首页信息结构

1. 简短问候与作者介绍：沿用现有真实内容。
2. 清楚的主标题与阅读入口。
3. 阅读指路：文章、关于两个真实入口，栏目不足时不虚构分类。
4. 最新文章：从博客内容自动生成，按时间倒序，展示真实日期和标签。

## 4. 视觉规范

- 近黑底色、柔和灰白正文、低对比细线，少量冷灰光感。
- 标题与正文形成清楚层级，正文行宽适合长文。
- 玻璃质感仅用于浮层和少量表面，不让正文背景复杂化。
- 卡片低幅度抬升、链接箭头轻移、内容短时交错浮现。
- 默认深色，保留主题切换。没有虚构统计、自动播放声音或持续抢注意力的动画。

## 5. 交互规范

- 搜索：沿用 Hextra 的全文搜索、快捷键和键盘结果选择。
- 全站目录：当前页面高亮，当前分组默认展开，保存手动展开状态及目录滚动位置。
- 正文目录：自动由 Markdown 标题生成，点击跳转，随阅读位置高亮；不生成空目录模块。
- 阅读进度：根据正文实际位置更新，提供回到顶部按钮。
- 动效：主要使用 cubic-bezier(0.16, 1, 0.3, 1)，小幅、短时；减少动态效果偏好下关闭位移与追踪。
- 无 JavaScript 时正文、普通链接、目录树仍然可以使用。

## 6. 背景猫：用户已选择

参考：黑底、灰白线稿、从底部探头、眼睛跟随鼠标。最新要求以用户提供的截图转透明底，替换此前的 Tabler 猫。

- 来源：本次对话中用户提供的参考截图，使用 imagegen 提取透明猫头，保留手绘轮廓，移除蜜蜂与横线。
- 素材、处理提示词及来源边界见 [素材记录](assets/cat-reference.md)。参考图的原作者与原图许可未核实，不声明其为 MIT 素材。
- 猫轮廓使用透明 PNG，眼睛通过独立 SVG 图层绑定；瞳孔移动范围受眼白半径限制。
- 瞳孔追踪参考现成公开眼睛跟随实现，保留来源及许可说明。
- 背景猫放在整个页面的右下角背景层，约占半屏宽，不截获正文点击；中等屏幕隐藏右栏时猫仍显示。
- 触屏与减少动态效果模式使用静态姿态；页面隐藏、猫不可见或指针停止后不持续运算。
- 不提取或分发 Wallpaper Engine 场景包。

## 7. 内容与维护

作者名、简介、个人链接集中配置在 hugo.yaml。头像使用当前 GitHub 账号的公开头像 URL；无指定头像时显示作者名首字母。GitHub 头像加载依赖访问其图片域名，头像更换后可能受浏览器/CDN 缓存影响。原有文章、URL、全文搜索与 CI/CD 保持可用。博客索引改为自动列出文章，减少手工维护链接。

## 8. 验收

- Hugo 正式构建成功，首页、博客索引、文章、关于、标签页正常。
- 桌面三栏，左侧个人区不随目录滚动，正文不溢出；手机单栏与可关闭抽屉。
- 搜索、目录折叠、锚点、阅读进度、主题切换、猫眼追踪正常。
- 支持键盘焦点、Escape 关闭、减少动态效果；没有运行时脚本报错。
- 第三方素材和许可留在仓库。
- 本地检查通过后提交、推送，通过现有 GitHub Actions 发布并核对实际站点。

## 9. 实施记录

已按本文档完成实现：

- 新增站点三栏布局覆盖与可配置个人信息，不更换 Hugo/Hextra 技术栈。
- 首页介绍、阅读指路、最近文章；博客索引自动列出文章；标签页、关于页保留。
- 导航树独立滚动与状态记忆；手机模态导航及目录；保留全文搜索与主题切换。
- 右栏按页面变化，正文目录高亮、阅读进度与回到顶部。
- 按最新要求将参考图转换为透明素材，猫脱离右栏固定到视口右下角；已有鼠标视线算法适配到新图坐标，离开页面时停止计算。
- 取消整体固定宽度，三栏、标题、正文和头像采用弹性尺寸；装饰图层裁切溢出，避免产生横向滚动条。
- 动效采用轻量 CSS 与按需动画帧，不添加前端框架。
